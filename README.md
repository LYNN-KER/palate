# Palate

主观语言模型品鉴。

同一句话，十张嘴。你只给语言打分。

[打开品鉴页](https://lynn-ker.github.io/palate/palate.html)，或下载 [`palate.html`](palate.html) 后用浏览器打开。

这是一个单文件网页。它不联网，不调用任何模型，也不上传你贴进去的题目和回答。分数存在打开它的那台浏览器里。换一台设备，记录不会跟着走。

## 它评什么

评的是语言，不是能力榜。

推理、工具、知识和事实对错都不单列。只有当它们把文章写坏了，才会从「贴题」或「清楚」里体现出来。同一道题问十次，比的是这十份回答读起来怎么样。

分数是口味。两个人打出的分不能相加，也不能拿去和公开跑分对照。

## 六项

六项等权。均分只计算已经打过的项。

| 项 | 看什么 |
| --- | --- |
| 清楚 | 一遍就懂，不绕、不堆 |
| 节奏 | 句子有呼吸，长短听得见 |
| 用词 | 落到实处，没有套话 |
| 分寸 | 贴这份题目，不端着也不油 |
| 声音 | 像会写的人，不是模型腔 |
| 贴题 | 问什么答什么，约束守住 |

刻度：

| 分 | 意思 |
| --- | --- |
| 1 | 站不住 |
| 2 | 弱 |
| 3 | 合格 |
| 4 | 好 |
| 5 | 想再读一遍 |

再点一次已经选中的数字，这一项收回，变回未打分。没打满六项的均分可以看，但榜上会注明，不要直接当成同一把尺子。

## 怎么用

1. 给这一轮起个名字。名字会变成顶部的轮次标签。
2. 把问他们的那一句原文贴进「题目」。同一句，不要改口。
3. 在「名单」里确认名称、型号和出品。
4. 去各自的窗口问完，把回答原样贴回对应卡片。不要先改。
5. 读完再打分。
6. 看榜。

顶部会显示入轮、已评和打满的数量。样本区的索引可以跳到对应卡片，打过分的会带上均分。

回答很长时，点「展开阅读」。想一次只看一份，点「逐条阅读」，用上一则、下一则翻页。没有光标停在输入框里时，键盘左右键也能翻。

## 名单

每一行有三栏。

- **名称**：你怎么叫它。榜、索引和卡片都跟着改。
- **型号**：你实际打开的那一个，比如 `Opus 4.6`。
- **出品**：Anthropic、OpenAI 这类。

预置十家：

| 名称 | 出品 |
| --- | --- |
| Claude | Anthropic |
| GPT | OpenAI |
| Grok | xAI |
| GLM | 智谱 |
| Gemini | Google |
| DeepSeek | 深度求索 |
| Qwen | 通义 |
| Kimi | 月之暗面 |
| MiMo | 小米 |
| MiniMax | MiniMax |

名称、型号和出品都能改。要把同一家的两个型号拆开比，点「另加一条」，自己填。

「移出」只是不进入这一轮，回答和分数还在，可以再请回来。预置的十家不能删除。自己加的那一条可以删除，删除后回答和分数一起丢掉。

这些改动只留在当前这一轮。

## 盲品

「开始盲品」会打乱卡片顺序，只留下甲、乙、丙、丁这样的编号。

揭盲之前：

- 名单收起来，免得对上号。
- 卡片不显示名称、型号和出品。
- 榜上只写编号。
- 这一轮不计入跨轮总览。

「打乱」会重新编号。编号跟的是这一次的顺序，不是模型本身。

「揭盲」之后编号还留着，方便对回蒙着时的印象。「蒙回」可以再藏起来。「退出盲品」会恢复原来的排列。

## 榜

榜按均分从高到低排。均分相同则并列，打满的项更多者靠前。

每一行下面有一道细线，长度按均分相对满分的比例画出。单项里的最高分会标出来；如果大家都一样，则不标。榜的末尾列出每一项的最高者。

有人还没打分、有人没打满、题目还空着，都会写在榜上。

## 跨轮

榜下面的总览把各轮里六项都打满的结果合在一起。

预置模型按固定身份合并，所以中途改了显示名称，仍算同一家。自己添加的模型按名称合并，名称不同就分成两行。

总览给出总均分、计入的轮数，以及六项各自的均分。当前轮如果还没揭盲，不计入，并会注明。

「同题再来」会新开一轮：题目、名称、型号、出品和谁在轮内都留下，回答、分数和印象清空。适合同一道题隔一段时间再问一次。

## 存档

所有内容都在浏览器的 `localStorage` 里，键名是 `palate:v1`。

- **复制报告**：当前轮的题目、榜、印象、跨轮总览和全部回答。
- **导出报告**：同一份内容的 Markdown 文件。
- **导出存档**：全部轮次的 JSON。
- **导入存档**：整份替换当前记录。导入前会再确认一次。

用无痕窗口，或者关掉浏览器的本地存储，记录会消失。换浏览器也读不到。要留下，就导出存档。

报告和存档都由你自己保存。这个仓库不接收、也不存放任何人的打分。
