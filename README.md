# Palate

主观语言模型品鉴。

同一句话，十张嘴。你只给语言打分。

打开 [`palate.html`](palate.html) 即可。单文件，不联网，不调用任何模型。分数存在这台浏览器里。

## 怎么用

1. 把同一道题贴进「题目」。
2. 在「名单」里写下你实际打开的名称、型号和出品。
3. 去各自的窗口问完，把回答原样贴回来。
4. 六项各打 1 到 5。再点一次，收回。
5. 看榜。

## 六项

清楚、节奏、用词、分寸、声音、贴题。等权。均分只计已打的项。跨轮总览只计六项都打满的轮次。

预置十家：Claude、GPT、Grok、GLM、Gemini、DeepSeek、Qwen、Kimi、MiMo、MiniMax。名称和型号都能改；要把同一家拆开比，另加一条。

## 盲品

「开始盲品」会打乱顺序，只留甲乙丙丁。揭盲之前名单收着。编号会留到揭盲之后，方便对回蒙着时的印象。

## 存档

「导出存档」得到 JSON。「导入存档」会整份替换。报告可以复制，也可以导出 Markdown。

数据键是 `palate:v1`，只在本机。
